SETUP (XAMPP)
1. Copy folder "bloodbank" to C:\xampp\htdocs\
2. Start Apache + MySQL in XAMPP
3. phpMyAdmin (http://localhost/phpmyadmin) -> Import -> database.sql
4. Open http://localhost/bloodbank/login.php
   Login: admin / admin123 (auto-created on first visit)
5. Hospital request page: http://localhost/bloodbank/request.php
DB settings: config.php (default user root, no password)
